# 口红质检员 批次色差检测

这是工程心理学课程项目的完善版本，当前已经完成颜色刺激、现场化任务简报、4 次工位培训、20 次正式检测、逐试次数据记录、信号检测统计、质检报告与分布教学实验室。

## 运行方式

无需安装依赖。直接双击 `index.html`，即可在现代浏览器中离线运行。

## 当前已完成

- 标准试色和待检试色使用 Canvas 绘制，两侧形状、面积、背景和纹理一致。
- 正常样本保留轻微随机色彩波动，异常样本只在此基础上整体降低明度。
- 支持正常/异常切换、容易/中等/困难三档难度和重新生成。
- 提供任务说明、批次编号、色号、设备状态、比较区、进度区、判断按钮和预览反馈。
- 支持桌面、平板和手机宽度，所有核心按钮可使用键盘操作。
- 开始前仍可使用第一阶段的开发预览控件；进入练习后会隐藏，避免泄露正式答案。
- 教学页对比正常波动与异常偏暗，并说明完整实验规则。
- 4 次练习包含即时答案和解释，不进入正式数据。
- 正式检测固定生成 10 个正常样本和 10 个异常样本并随机排序。
- 每次包含 500 ms 准备、1500 ms 观察、遮挡与单次作答。
- 页面在准备或观察期间失焦会暂停，本次不记录，返回后必须重新播放。
- 每条正式记录包含真实类别、回答、结果分类、颜色、难度、时间和响应时长。
- 完成后生成 H/M/FA/CR 四格表，以及命中率、虚报率、准确率、玩家估计 d′ 和判断标准 c。
- 报告区分模型设置 d′ 与玩家估计 d′，并解释 c 的方向和极端比例校正。
- 结果页明确拆分漏检与误拦风险，解释为什么准确率不足以代表质检质量。
- 结果页提供 d′、c 与两类分布的联动图，可实时查看预计命中率与虚报率。
- 开始前可在 d′=0.5–3.0 之间连续调节刺激难度，也可使用容易、中等、困难三个快捷档位。
- 提供普通生产、新品第一批、投诉后返工三种口语化任务背景；实验长度始终固定为20次。
- 结果页新增ROC曲线，c变化时工作点沿同一条曲线移动，并显示AUC。
- 先验概率和四种结果价值可编辑，页面会计算最优β与建议c，并可一键应用到分布图和ROC图。
- 每轮结束后在本机保存汇总指标，报告页展示最近5轮准确率与玩家d′趋势，并可随时清除。
- 情景采用灌装线驻线质检任务，批次、工单和样本编号各司其职；同一轮批次与工单保持不变。
- 界面明确标注屏幕模拟不代替分光测色仪和真实标准光源箱，避免虚构仪器精度。

## 文件结构

- `index.html`：页面结构和可访问文本。
- `styles.css`：暖白与莓红视觉系统及响应式布局。
- `script.js`：刺激生成、Canvas 绘制和预览交互。
- `REQUIREMENTS.md`：完整需求、阶段边界和验收清单。
- `TESTING.md`：自动统计案例、浏览器流程和待人工确认项目。
- `FINAL_CHECKLIST.md`：最终交付状态、评分覆盖与现场确认项目。

## 当前刺激模型

参考色固定为莓红色系。正常样本含少量色相、饱和度和明度随机波动；异常样本在相同波动基础上按难度额外降低明度。模型分离度可在0.5–3.0之间连续调节，2.0、1.2、0.6是三个快捷档位，仅代表刺激生成参数，不等于参与者实际测得的 d′。

## 数据检查

逐试次数据只保存在当前页面内存中，重新开始会清空。为了支持多轮比较，页面使用浏览器本地存储保存最近10轮汇总指标，报告只展示最近5轮；不保存逐次颜色、作答时间或身份信息。用户可在报告页清除本机记录。开发检查时可读取 `window.experimentData.practice`、`window.experimentData.formal`、`window.experimentData.history` 和 `window.experimentData.status`。

报告中的命中率、虚报率和准确率使用原始比例；d′ 与 c 使用 log-linear 校正比例 `(计数 + 0.5) / (该类别总数 + 1)`，因此全对、全选正常或全选异常时仍会得到有限数值。
